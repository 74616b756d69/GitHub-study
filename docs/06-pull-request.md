## Pull Request とは？

Pull Request は、**「自分の変更を元のリポジトリに取り込んでください」** という提案です。

略して **PR**（ピーアール）と呼ばれることが多いです。

## 1. PR を作成する

### 方法 A: GitHub が自動で提案してくれる場合

push した直後にフォーク先のページを開くと、黄色いバーで **「Compare & pull request」** が表示されることがあります。これをクリックすると簡単に PR を作成できます。

### 方法 B: 手動で作成する場合

1. **元のリポジトリ**（`Akasan-T/GitHub-Studie`）のページを開く
2. **「Pull requests」** タブをクリック
3. **「New pull request」** をクリック
4. **「compare across forks」** をクリック
5. 以下を設定:
   - base repository: `Akasan-T/GitHub-Studie` / base: `main`
   - head repository: `あなた/GitHub-Studie` / compare: `feature/add-自分の名前`
6. **「Create pull request」** をクリック

## 2. PR の書き方（重要！）

PR の説明は **レビュアーへの手紙** です。
レビュアーがあなたの変更を理解できなければ、正しくレビューできません。

### 良い PR の例

> このリポジトリには [サンプル PR](https://github.com/Akasan-T/GitHub-Studie/pulls) があります。
> 実際の PR がどう見えるか確認してみましょう。

```markdown
## 変更内容

自己紹介カードを追加しました。
- ファイル: `exercises/participants/taro-yamada.md`
- 名前、自己紹介、好きな技術、ひとことを記載

## 変更の理由

ハンズオン演習として自己紹介カードを作成しました。

## 確認したこと

- [x] ファイル名が正しい（`exercises/participants/taro-yamada.md`）
- [x] Markdown の表示が崩れていないことを確認した
- [x] 他の人のファイルを変更していない
- [x] 個人情報（電話番号・住所など）を含めていない
```

### 悪い PR の例

```markdown
変更しました
```

```markdown
自己紹介です。よろしくお願いします。
```

何を変更したのか、なぜ変更したのか、何も伝わりません。

## 3. PR に書くべき 3 つのこと

| 項目 | 書くこと | なぜ必要？ |
|------|---------|----------|
| **What（何を）** | 変更したファイル・内容の概要 | レビュアーが変更の全体像を把握するため |
| **Why（なぜ）** | 変更の目的・背景 | 「この変更は本当に必要か」を判断するため |
| **How（どうやって確認）** | テスト方法・確認手順 | レビュアーが動作確認できるようにするため |

### 実務での PR はこうなる

```markdown
## 変更内容（What）

ユーザー登録画面にメールアドレスのバリデーションを追加しました。
- 形式チェック（@が含まれているか）
- 重複チェック（既に登録済みでないか）

## 変更の理由（Why）

不正な形式のメールアドレスで登録できてしまい、
パスワードリセットのメールが届かないという問い合わせが
先週だけで15件発生していたため。

## 確認方法（How）

1. ユーザー登録画面を開く
2. メールアドレス欄に `test` と入力して送信 → エラーが表示されること
3. メールアドレス欄に `test@example.com` と入力して送信 → 正常に登録されること
4. 同じメールアドレスで再度登録 → 「既に登録済みです」と表示されること
```

## 4. PR の確認チェックリスト

PR を作成する前に、自分で確認しましょう:

- [ ] **タイトル** が変更内容を表している（「add: 自己紹介カード（山田太郎）」など）
- [ ] **変更内容・理由・確認方法** を書いた
- [ ] **Files changed** タブで、変更内容が正しいか確認した
- [ ] 自分のファイル **だけ** が変更されている
- [ ] 余計なファイル（`.DS_Store` など）が含まれていない
