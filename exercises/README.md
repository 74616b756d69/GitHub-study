# 演習: 自己紹介カードを追加しよう

## 目的

Git と GitHub の基本操作を、実際に手を動かして体験します。

## やること

`participants/` フォルダに自分の自己紹介カード（Markdown ファイル）を追加して、Pull Request を出してください。

## 手順

1. [サンプルカード](participants/example-taro.md) を参考に、自分のカードを作成する
2. ファイル名は `自分の名前.md`（例: `tanaka-hanako.md`）
3. 内容は自由ですが、以下のテンプレートを使うとスムーズです

## テンプレート

```markdown
# あなたの名前

## 自己紹介
ここに自己紹介を書いてください。

## 好きな技術・興味のある分野
- 例: Python
- 例: Web 開発
- 例: データ分析

## ひとこと
ここに一言メッセージを書いてください。
```

## 注意

- 個人情報（電話番号・住所など）は書かないでください
- 他の参加者のファイルは編集しないでください
- 困ったら [質問用 Issue](https://github.com/Akasan-T/GitHub-Studie/issues/new?template=question.md) を立ててください
